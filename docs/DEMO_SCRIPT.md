# Seven-minute demonstration

1. **Purpose and evidence (45 seconds):** introduce Group A and Option 3. Show historical date coverage and actual record counts. Explain provider forecasts, without fitted models.
2. **Sri Lanka map (60 seconds):** choose two district reference points, zoom the real district map, change the date range. Explain why point colours are not inundation polygons.
3. **History and EDA (90 seconds):** show rainfall/temperature, a histogram, correlation matrix and monsoon comparison. Explain paired data counts and partial-year rates.
4. **Flood interpretation (60 seconds):** show accumulated rain, modelled flow and a seasonal anomaly. Replay one episode. Explain the screening score and absence of confirmed flood labels.
5. **Upcoming conditions (60 seconds):** show the 16-day provider forecast and retrieval time. Explain ensemble P25/P75 and why these are not return periods.
6. **Global tools (45 seconds):** search a place, enter coordinates, load elevation and weather. GPS is optional; prepare coordinates if location permission is denied.
7. **Engineering and limits (60 seconds):** show FastAPI docs, Parquet schema and actual Spark/cloud evidence if your team has run it. Distinguish the measured local SQL benchmark from distributed execution. Finish with actual individual contributions.
